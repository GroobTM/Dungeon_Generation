<h1>Dungeon Generation</h1>
<p>This project was created using the Unity game engine (6000.4.0f1). The project used the drunkard's walk and wave function collapse procedural content generation techniques to generate dungeon layouts.</p>
<h2>Instructions</h2>
<p>This project used assets from <a href="https://assetstore.unity.com/packages/3d/environments/low-poly-modular-village-lowpoly-medieval-fantasy-series-258073">Low Poly Modular Village - LOWPOLY MEDIEVAL FANTASY SERIES</a>. You do not need to buy these assets to use the dungeon generator, as alternative primitive assets are provided.</p>
<ol>
  <li>Install the Unity Hub from the <a href="https://unity.com/">Unity website</a>.</li>
  <li>Clone this repository.</li>
  <li>Launch the Unity Hub and select the "Projects" tab.</li>
  <li>Select the "Add" button followed by the "Add project from disk" button from the resulting drop-down menu.</li>
  <li>Select the repository on your local disk.</li>
  <li>Select the "Dungeon Generation" entry from the list of projects.</li>
  <li>Install the required Unity game engine version when prompted.</li>
  <li>(Optional) Add the required assets:
	  <ol>
	    <li>Add <a href="https://assetstore.unity.com/packages/3d/environments/low-poly-modular-village-lowpoly-medieval-fantasy-series-258073">Low Poly Modular Village - LOWPOLY MEDIEVAL FANTASY SERIES</a> to your assets.</li>
		  <li>Navigate to "Asset Store" -> "My Assets" -> "Low Poly Modular Village - LOWPOLY MEDIEVAL FANTASY SERIES", then download and add the assets to the project.</li>
		  <li>Navigate to the "Polytope Studio\Lowpoly_Village\URP" folder.</li>
		  <li>Open and import the contents of "PT_Village_URP_17.unitypackage".</li>
	  </ol>
  </li>
  <li>Select the "SampleScene" scene from the "Scenes" folder in the Unity Editor.</li>
  <li>Select the "Dungeon Generator" game object from the hierarchy.</br>
  <ul>
  <li>The "Dungeon Generator" script can be assigned to any game object.</li>
  <li>Tile sets can be found in the "Scripts/Tile Sets" folder.</li>
  <li>The room cell prefab can be found in the "Prefabs" folder.</li>
  </ul>
  </li>
</ol>
